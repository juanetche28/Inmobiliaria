# Etcheverry Brothers – Web inmobiliaria (React + Vite + Firebase)

1. Creá el proyecto en Firebase y pegá la config en `src/firebaseConfig.js`.
2. Activá Authentication (Email/Contraseña) y Firestore; pegá `firestore.rules` en Firestore > Reglas.
3. Creá el admin (ver manual / instrucciones del chat).
4. `npm install` y `npm run dev`.
5. `git push` a `main` publica en GitHub Pages (Settings > Pages > Source: GitHub Actions).
